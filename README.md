# Мини-Склад (kb99-1c-mini-sklad)

Учебная конфигурация 1С:Предприятие, созданная в рамках курса по разработке.
Минимальный контур учёта: справочники товаров и контрагентов, документы поступления и реализации.

## Что внутри

- **Справочники:**
  - `Товары` — номенклатура товаров.
  - `Контрагенты` — поставщики и покупатели.
- **Документы:**
  - `Поступление` — приход товара (реквизиты: контрагент, товар, количество).
  - `Реализация` — расход товара (реквизиты: контрагент, товар, количество).
- **Подсистема:** `Мини-Склад` — раздел интерфейса со всеми объектами и командами создания.

## Как открыть

Конфигурация выгружена в файлы (XML + модули). Чтобы загрузить её в 1С:

1. Откройте **Конфигуратор** 1С:Предприятие (версия платформы 8.3).
2. Создайте новую пустую конфигурацию или откройте существующую.
3. В меню выберите **Конфигурация → Загрузить конфигурацию из файлов…**
4. Укажите папку с выгрузкой (корень репозитория) и нажмите **«Загрузить»**.
5. После загрузки обновите конфигурацию базы данных (**F7**) и запустите **1С:Предприятие** (**F5**).
6. В интерфейсе появится раздел **«Мини-Склад»** с объектами и командами.

## Структура репозитория

- `Configuration.xml` — корневой файл конфигурации.
- Папки объектов (`Catalogs`, `Documents`, `Subsystems` и т.д.) — исходники в виде XML.
- `*.bsl` — тексты модулей (если есть).
- `.gitignore` — исключённые служебные файлы.
